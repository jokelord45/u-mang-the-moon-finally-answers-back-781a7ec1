# The Moon Finally Answers Back

After four billion years of wishes, howls, and 2 a.m. promises, the Moon finally replies — and it turns out nobody ever asked how *it* was doing. One line, in the Moon's own wry, weary voice, landing the comeback it has been holding in since the first human looked up and made a wish.
